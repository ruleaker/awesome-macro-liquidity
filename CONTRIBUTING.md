# Contributing

Thanks for considering a contribution. This list aims for **signal, not coverage** — every entry should earn its place.

## Suggesting a resource

Open a Pull Request that adds the resource to the appropriate section. Each entry must follow the format:

```markdown
- [Name](URL) — One-line description explaining *why it matters* for tracking liquidity.
```

## Quality bar

Resources should meet **all** of the following:

- **Actively maintained.** Data sources updated within the last year; thinkers still publishing.
- **Substantively about liquidity.** Not generic macro/finance commentary. The entry should help someone understand the *plumbing of capital* — central bank operations, monetary aggregates, funding markets, on-chain stablecoin flows, etc.
- **Accessible.** Either free, or with a meaningful free tier. Paid-only resources are accepted only if there is no comparable open alternative (mark with `(paid)`).
- **Direct.** Link to the primary source where possible (e.g., link to FRED series, not to a blog post that quotes the FRED series).
- **Original.** Not a re-aggregation of resources already on this list.

## What gets rejected

- Generic finance/investing content with no liquidity angle
- Affiliate-linked product pages
- Telegram/Discord/Twitter accounts without a stable home
- Duplicates of existing entries with weaker framing

## Format

- Keep description **under 25 words**.
- Use `(paid)` suffix for paywalled resources.
- Sort entries within a section by relevance, not alphabetically.

## PR title

Use the format: `add: <Resource Name>` or `update: <Resource Name>` or `remove: <Resource Name> — <reason>`.
